# Materiały pomocnicze (nie do scalenia z `main`)

Ta gałąź nie ma wspólnej historii z `main` i nie jest przeznaczona do scalenia. Zawiera pliki, które pomagały w budowie projektu, ale nie są jego częścią:

- `specs/`: wymagania i plan wdrożenia z listą kontrolną,
- `skills/`: skille użyte przy pracy z asystentem AI, razem ze źródłami w `skills/ZRODLA.md`.

Kod i dokumentacja projektu trafiają na gałąź `filip/projekt`.
